Thanos Querier

The Thanos Querier implements the Prometheus HTTP v1 API. It gathers the data needed to evaluate PromQL queries from underlying StoreAPIs (like Sidecars, Store Gateways, and Rulers), evaluates the query, and returns the result. It is fully stateless and horizontally scalable.

Deep Internal Working

When a user executes a PromQL query, the Querier performs the following steps:

  1. Scatter: The Querier analyzes the query and concurrently fans out gRPC StoreAPI requests to all known targets (Sidecars, Store Gateways, etc.).
  2. Gather: It collects the raw time-series data from these underlying components.
  3. Deduplication: If high-availability (HA) Prometheus pairs are scraped, the Querier merges overlapping series at runtime based on configured replica labels.
  4. Evaluation: It evaluates the PromQL expression on the gathered, deduplicated data using its PromQL engine.
  5. Response: The result is formatted and returned to the client. If a target is unavailable, the Partial Response Strategy determines whether to abort the query or return a warning.
