Module: Sidecar Internals

Thanos Sidecar

The Thanos Sidecar is the main component that integrates a vanilla Prometheus instance into the Thanos ecosystem. It runs alongside Prometheus, bridging local storage with global observability.

Deep Internal Working

The Sidecar has two primary responsibilities:

  1. Store API (Serving Data): It implements Thanos's gRPC Store API. When Thanos Querier needs recent data, it asks the Sidecar, which translates the request into Prometheus's local TSDB queries.
  2. Block Uploading (Long-term Storage): It watches Prometheus's local data directory. When Prometheus cuts a new persistent TSDB block (usually every 2 hours), the Sidecar detects it and uploads the block to an Object Storage bucket.

Guided Examples

Example 1: Store API Queries

Goal: See how Sidecar handles queries for recent data.

  1. Click "Simulate Query (via Store API)".
  2. Observation: The Sidecar intercepts the gRPC request and fetches data directly from the running Prometheus instance.

Example 2: Block Upload Flow

Goal: Observe how long-term storage is populated.

  1. Click "Prometheus: Cut New Block". A new block appears on local disk.
  2. Observation: The Sidecar detects the new block. After validating it, it uploads it to Object Storage, ensuring the data is backed up globally.

Example 3: Configuration Playground

Goal: Understand key CLI flags.

Toggle flags in the Controls panel and observe their effects:

  • --prometheus.url: Tells Sidecar how to reach Prometheus's API for Store API queries.
  • --tsdb.path: The local directory Sidecar watches for new blocks.
  • --objstore.config-file: If omitted, Sidecar won't upload blocks.

Failure Modes

  • Sidecar cannot read TSDB: If the Sidecar lacks file permissions for Prometheus's data directory, block uploads will fail silently or log errors.
  • Prometheus API unreachable: If --prometheus.url is wrong, Store API queries will fail.
  • Block overlaps: If Prometheus's min/max block times overlap unexpectedly, Thanos compactor will complain later. The sidecar only uploads; it doesn't fix overlaps.
