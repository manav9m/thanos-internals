The last jump

Decode one chunk ref

A chunk ref is a uint64. The upper 32 bits store the chunk segment sequence. The lower 32 bits store the byte offset inside that segment file.

Chunk file view

Remember these formulas

segment_seq = ref >> 32
in_file_offset = ref & 0xFFFFFFFF
filename = fmt.Sprintf("%06d", segment_seq + 1)
