One folder, four things

Start with the block directory

A persistent Prometheus block is a folder named by a ULID. Inside it, you will always find chunks/, index, meta.json, and tombstones.

01EM6Q6A1YPX4G9TEB20J22B2R/ |- chunks/ | |- 000001 | '- 000002 |- index |- meta.json '- tombstones

Click each block file

This is the simplest possible question on this page: what does each file do?

What to remember from this page

The index is the lookup map. This whole track is mainly about that file.
Chunk files store compressed samples. They do not store labels for every sample.
meta.json gives block metadata. It tells you the block identity and time range.
tombstones record deletions. Queries still need to respect them.
Why this page comes first
If you do not know the job of each file, the later byte-offset labs feel random. This page gives the storage map first.
