Object Storage Lab

The immutable foundation of Thanos. Learn how TSDB blocks are stored, structured, and accessed in remote buckets.

Purpose

Thanos uses Object Storage (like S3, GCS, Azure, etc.) as the primary, infinite storage layer for metrics and metadata. This provides long-term retention and high availability for historical data.

Internal Working

Data is stored in native Prometheus TSDB blocks. Each block is a directory named with a ULID containing chunk files, an index, and a meta.json file. All files in object storage are strictly immutable. Modifications (like compaction or deletion) require creating new blocks and marking old ones for deletion.
